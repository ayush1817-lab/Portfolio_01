# Small Builds media

The build pages work without any images: code-drawn diagrams carry each story.
To add real media, save a file here with one of the names below (any of
`.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`). It appears in its spot on the next
build; empty slots stay hidden. Alt text and captions live in `src/builds/media.ts`.

| Build       | File name              | Where it appears                    | What to show                                                |
| ----------- | ---------------------- | ----------------------------------- | ----------------------------------------------------------- |
| 3D Pipeline | `pipeline-asset-sheet` | Workflow section, after the 8 steps | The Excel asset inventory produced from a scene script      |
| 3D Pipeline | `pipeline-review-page` | Workflow section, after the 8 steps | The internal web page where generated models await approval |
| Détente     | `detente-product`      | "What it is" section                | Large bracelet / product image                              |
| Détente     | `detente-states`       | Under the interaction sequence      | Close-up of the calm → red → green state transition         |
| Voice Agent | `voice-agent-demo`     | "What it is" section                | The prototype running (a still from a demo, or your setup)  |

Crop wide (around 16:10) for the best fit.
